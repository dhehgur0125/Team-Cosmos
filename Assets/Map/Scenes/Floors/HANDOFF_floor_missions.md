## 1층 규칙 (사용자가 정한 것)
- 준비 3가지 (순서 없음, 나눠서 가능)
  - 전력 모듈(연료 접속실 바닥, 2층 리프트가 닿는 자리) + 공구(정비 작업실 작업대 위)를 **한 대원이 둘 다 들고** 보조 우주선 방의 설치 자리에 설치. 둘 다 사라진다.
  - 연료 접속실 밸브에서 연료 라인 연결.
  - 고정 장치 2개(화물 적재실, 지상 정비 구역): 한쪽을 풀고 **10초 안에** 다른 쪽. 늦으면 다시 잠김. 살아 있는 대원이 1명이면 시간 제한 없음.
- 발사 관제실 콘솔에서 격납고 문 열기 → 경보(소리 듣는 몬스터 전부 호출) + 관제실 북쪽 베이 통로 문이 열림. 문 뒤에 촉수형·눈 없는 대형이 갇혀 있다.
- 보조 우주선 방 콘솔에서 점화 → 3분(한 명이라도 살아 있으면 흐름), 30초마다 엔진 소음.
- 3분 뒤 격납 베이(관제실 북쪽 통로 → 계단)의 탈출선 Discovery 탑승 구역에 살아 있는 대원이 모두 들어가 3초 → 탈출.
- 탈출하면 `GameOverScreen.ShowEscape`가 "ESCAPED" 화면(탈출한 대원 / 남겨진 대원)을 띄우고 같은 방 대기실로 돌아간다.

## 시험 방법
- 층 씬을 열고 Play (혼자, 오프라인). 죽으면 게임 오버로 넘어가므로 콘솔에서 `FpsHealth.DamageBlocked = true`.
- Unity 창에 포커스가 없으면 커서 잠금이 풀려 상호작용 안내가 안 뜬다 (정상).

## 아직 안 한 것 / 알려진 것
- 2인 이상 실제 접속 시험 (모든 층).
- F를 실제로 길게 누르는 조작 (코드로 대신 실행해 확인함).
- 3층에서 전송한 항로 데이터, 2층에서 내려보낸 전력 모듈은 1층과 실제로 이어져 있지 않다 (1층에 모듈이 그냥 놓여 있고, 점화는 3층 결과를 보지 않음).
- 엔딩 연출(탈출선 출발 장면) 없음. 화면만 뜬다.
- 5층 임무, 전멸 시 그 층 재시작, 인원별 보정 없음.
- 2층 `F2MissionDirector.InteractHeld`는 키 설정과 상관없이 F 고정 (1·3층은 키 설정을 따름).

## 1층 확인 기록
- 배치 메뉴 실행 성공: 장치 6개, 격납고 문, 물건 2개, 몬스터 5마리. 모든 장치·물건에 서서 조준할 수 있는 자리가 있는지 검사함.
- 혼자 실행(오프라인)으로 확인한 것: 물건 없이 설치 자리 안내 문구 → 전력 모듈·공구 줍기 → 공구 없이 설치 거절 → 설치(둘 다 사라짐) → 멀리서 누르면 거절 → 연료 라인 → 고정 장치 2개(혼자라 시간 제한 없음) → 준비 전 격납고 문 거절 → 격납고 문 열림(문 올라감, 쪼꼬미·촉수형이 소리 듣고 이동) → 문 열기 전 점화 거절 → 점화·카운트다운(시험용 12초) → 탑승 구역 3초 → ESCAPED 화면 → 로비 씬 이동. 콘솔 오류 없음.
- 확인 못 한 것: 고정 장치 10초 제한과 다시 잠김(대원 2명 이상일 때만 적용 → 2인 접속 필요), 탑승 인원 판정(여럿), 남겨진 대원 표시, 실제로 걸어서 베이까지 가는 길(길 찾기 데이터로만 확인), 3분 동안의 실제 난이도. 마지막에 고친 탈출 화면 배경색(초록빛)은 화면으로 다시 보지 않음.

## 4층 (2026-11-17 구현 완료)
규칙 (사용자가 정한 것 + 설계도)
- 준비 (순서 없음): 전력 셀 보관실 바닥의 전력 셀 3개를 보조 발전기에 끼우기 / 냉각 설비실·배관 구역의 냉각 밸브 2개 열기 / 정비 작업장 작업대 위 수리 공구(1층과 같은 `ToolKit`) 챙기기.
- 전력 셀(`PowerCell`)은 무거운 물건: 한 대원이 1개만 들 수 있고(`FpsInventory.TryAdd`), 드는 동안 달리기·왼쪽 클릭(사격 등)이 안 된다(`FpsInput.ApplyHeavyLoad`, `FarmingItems.IsHeavy`).
- 발전기실 콘솔에서 가동 → 90초. 살아 있는 대원이 발전기실 안에 있어야 진행, 15초마다 소음(쪼꼬미). 35~65% 사이에서 한 번 고장 → 공구를 가진 대원이 발전기에서 수리(공구는 안 사라짐).
- 가동이 끝나면 배전실 + 전력 제어실 스위치를 10초 안에 둘 다 (늦으면 다시 내려감, 살아 있는 대원이 1명이면 제한 없음) → A 계단만 열림.
- 몬스터: 촉수형 1(배관 구역), 쪼꼬미 1(정비 작업장). 맵 표시(마커)의 순찰 지점 사용.

파일: `Mission/F4MissionDirector.cs`, `Editor/F4MissionSetup.cs`(메뉴 6e), `MissionInteractable.Kind` 21~24, `F2MissionItemAssets.BuildPowerCell`. `F3MissionSetup.Wrap`은 소품의 충돌 범위까지 감싸도록 고침(4층 발전기가 자기 충돌 범위에 가려 조준이 안 됐음. 3층·1층은 다시 배치하지 않았고 다음에 다시 만들 때 적용됨).

확인 (혼자 실행, 오프라인)
- 셀 1개 든 상태에서 두 번째 줍기 거절(바닥에 그대로 남음) → 끼우면 다시 주울 수 있음 → 3개 장착.
- 밸브 전 가동 거절, 가동 전 스위치 거절, 멀리서 누르기 거절.
- 가동(시험용 12초) → 고장 발생·안내 문구·쪼꼬미가 소리 난 곳으로 이동 → 공구 없이 수리 거절 → 공구로 수리(공구 유지) → 완료.
- 스위치 2개(혼자라 시간 제한 없음) → A 계단만 허용, B는 거절 → 내려가기 → 3층 씬 도착, 3층 임무 시작. 콘솔 오류 없음.

확인 못 한 것
- 전력 셀을 든 채 실제로 달리기·사격 키를 눌러 보는 것 (코드상 입력을 지우는 3줄. 키를 대신 눌러 줄 수 없었음).
- 발전기실을 비우면 멈추는 것 (시험이 너무 빨리 끝나 못 봄. 3층 내려받기와 같은 코드).
- 스위치 10초 제한·다시 내려감, 여러 명이 셀을 나눠 드는 것 → 2인 접속 필요.
- F를 실제로 길게 누르는 조작, 난이도.
