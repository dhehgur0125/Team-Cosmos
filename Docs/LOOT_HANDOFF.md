- Stage2_Ship_2f: 기존 상자 31개에 LootContainer 연결. 기존 파밍·임무 픽업 22개는 렌더러와 콜라이더를 숨겨 임무 활성화 및 네트워크 식별자를 보존.
- 비어 있던 상자의 추가 보상 후보 15개. 상자 ID와 세션 시드로 50% 확률 판정. 기존 임무 아이템에는 꽝 확률을 적용하지 않음. 배터리와 건물도면은 각각 최소 1개 보장.
- 탐지 50m. LootContainer.CanScan은 시드 준비 완료 및 실제 활성 보상 존재 여부로 판단. 꽝·소진 상자 제외. 이미 수색한 상자라도 후속 임무 보상이 활성화되면 탐지 가능.
- F를 1.5초 눌러 수색. 진행 바 표시. 해제·대상 이탈·사망·일시정지 시 초기화. 한 번 완료하면 F를 놓아야 다음 수색 가능.
- 인벤토리 가득 찬 경우 수색 및 획득 취소, 보상 보존, 안내 표시.
- 배터리는 탐지기/스턴/치유 고유 장비 충전, 무전기 제외. 온라인 스턴/치유는 서버 응답 후 소비. 2인 실제 세션 검증은 별도 필요.
- Map enum 번호 유지, 표시명만 건물도면. 슬롯 선택 후 좌클릭으로 열기, 좌/우클릭 또는 슬롯 변경으로 닫기. 소비되지 않음.
- Resources/FloorPlans/Stage2_Ship_1f~5f.png에 원본 5장 등록. 현재 FpsMapItem.CurrentPlanPath는 2층 고정. 다른 층 전환 UI는 아직 활성화하지 않음.
- 이미지 원본을 자르거나 변형하지 않고 공통 1120x850 영역에서 비율 유지/중앙 정렬. 제목/닫기 안내 별도 배치. 무압축, 밉맵 없음, NPOT 크기 유지로 도면 글자 선명도 보존.
- 검증 메뉴: VOID LAST/Loot/Validate Current Floor. 결과: Library/ContainerLootValidate.report.
- 상자 변환 메뉴는 새 층에 적용할 때만 사용. 기존 적용 씬에서 불필요하게 재실행하지 말 것.

## 2026-11-27 추가 수정
- 탐지: 상자의 실제 활성 보상 중 임무 아이템(검역 카드, 절단기 등)이 있는 경우만 표시. 일반 파밍/배터리/도면만 있는 상자는 탐지 제외. 표시에는 임무 아이템 이름 포함. 보상을 획득하면 마커 및 남은 발광 해제.
- 층별 도면: 기존 Map=13은 2층 유지. MapFloor1/3/4/5를 enum 끝에 추가. 각 도면은 소지하면 어느 층에서나 해당 이미지를 열 수 있음. 상자 보상은 CanLootOnFloor로 현재 층 도면만 허용. 2층 보상 배치에는 다른 층 도면을 추가하지 않음.
- 모델: 파란 종이, 흰 도면 선, 양끝 말림. 각 층 1개 합쳐진 메시/3개 재질. Resources/FarmingItems의 5개 도면 프리팹에 Model 연결하여 월드 드랍/1인칭/3인칭 모델 공통 사용. BlueprintItemSetup 메뉴로 재생성 가능.
- 숨긴 보상: 프리팹 모델 교체 후 새 렌더러가 생겨도 FpsWorldPickup.OnEnable에서 storedInContainer 보상의 렌더러/콜라이더/탐지를 비활성화.
- 배터리: 온라인 여부를 실제 충전 NetworkBehaviour의 IsSpawned로 판단. 요청 식별자로 지연 응답이 새 요청을 완료시키지 않게 처리. 응답 대기는 실시간 8초로 제한; 연결 종료/기한 초과 시 사용 상태 해제, 배터리 보존. 대기 중 타인 치료 애니메이션 및 0% 진행 표시 수정.
- 네트워크 장애 시 서버에서 이미 충전을 적용했으나 결과를 받지 못한 경우에 대한 완전한 거래 복구는 별도 시스템 필요. 실제 2인 지연/재접속 테스트 권장.
- 회귀 검사: VOID LAST/Loot/Validate Blueprint and Battery Revision. 현재 씬을 바꾸지 않고 2층을 PreviewScene으로 열어 확인. 결과 Library/LootRevisionValidate.report, 모델 미리보기 Library/BlueprintPreview.png.
