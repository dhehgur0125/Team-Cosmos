## 1. 기획 의도

혼자 하는 호러 게임은 무서움을 혼자 견뎌야 합니다. VOID LAST는 **친구와 함께 무서워하고, 서로 의지해야 살아남는** 경험을 목표로 합니다.

- **긴장감**: 어둠, 소리, 부족한 탄약. 몬스터를 다 쓰러뜨리기보다 피하고 숨는 쪽이 유리하게 만든다.
- **협동이 필요한 구조**: 혼자서는 손이 모자라도록 임무를 짠다. 한 명이 장치를 다루는 동안 다른 대원이 지키고, 멀리 떨어진 스위치를 동시에 눌러야 한다.
- **역할 나누기**: 대원마다 다른 고유 아이템을 들고 시작한다. 누가 무엇을 맡을지 대기실에서부터 이야기하게 만든다.
- **소통**: 가까이 있으면 목소리가 들리고, 멀리 있으면 무전기가 있어야 대화할 수 있다. 정보를 나누는 것 자체가 게임이 된다.

## 2. 배경 이야기

대원들은 우주 정거장 옆에 정박한 5층짜리 우주선의 승무원이다.
어느 날 하층 화물 구역으로 **외부 생명체가 침입**한다. 함내 방송은 1층 격납 베이의 탈출선으로 대피하라고 알린다.

하지만 우주선 시스템이 곳곳에서 망가져 있어, 층마다 시스템을 복구해야 아래층 계단이 열린다.
생명체들은 소리에 반응한다. 대원들은 맨 위 5층 승무원 구역에서 출발해, 소리를 죽이며 한 층씩 내려가야 한다.

## 3. 게임 흐름

```
처음 화면 → 로비 → 대기방 (고유 아이템 고르기·준비)
   → 5층 → 4층 → 3층 → 2층 → 1층 → 탈출 (ESCAPED 화면)
                                  ↘ 모두 쓰러짐 → 게임 오버
   → 같은 방 대기방으로 돌아옴
```

- **처음 화면**: 시작, 설정, 끝내기
- **로비**: 방 만들기, 방 코드로 참가, 글자·음성 채팅
- **대기방**: 대원마다 고유 아이템을 하나씩 고르고 준비. 방장이 게임을 시작
- **층 이동**: 계단 끝에 모여 모두 상호작용 키를 눌러야 함께 다음 층으로 이동
- **끝**: 탈출하거나 모두 쓰러지면 결과 화면이 뜨고, 같은 방 대기방으로 돌아가 다시 시작할 수 있음

## 4. 대원

| 항목 | 값 |
| --- | --- |
| 체력 | 100 |
| 권총 | 탄창 10발, 시작 예비 탄 20발 |
| 손전등 | 권총에 달려 있음. 권총을 들고 있을 때만 켜고 끔 |
| 지구력 | 7초 동안 달릴 수 있음. 다 쓰면 40%가 찰 때까지 못 달림. 점프는 10% 사용 |
| 앉기 | 발소리가 나지 않음. 일부 몬스터(개구리형)는 앉은 대원을 못 봄 |
| 물건 칸 | 1번 권총, 2번 근접, 3번 고유 아이템, 4~6번 주운 물건 |

- **쓰러지면**: 그 층 어딘가에 고치(Cocoon)로 갇힌다. 동료가 고치를 5발 쏘면 구출되고, 체력 절반으로 다시 일어난다.
- **쓰러진 동안**: 살아 있는 동료 시점으로 관전하고, 쓰러진 대원끼리 음성 채팅을 한다.
- **계단실은 안전 구역**: 계단실 안의 대원은 몬스터가 보거나 공격할 수 없다. 대신 계단실 밖으로 나가야 임무를 할 수 있다.

## 5. 고유 아이템

대기방에서 대원마다 하나씩 고른다. **같은 아이템은 한 명만** 고를 수 있다. 3번 칸에서 사용한다.

| 아이템 | 효과 | 역할 |
| --- | --- | --- |
| 스캔 | 임무 물건·목표·고치 위치를 알려 줌. 대신 눈 없는 몬스터가 몰려옴 | 길 찾기 |
| 무전 | 무전기 2개로 시작, 하나는 동료에게 줄 수 있음 | 소통 |
| 힐러 | 1.5초 뒤 체력 50 회복. 왼쪽 클릭은 나, 오른쪽 클릭은 앞의 동료. 3회 | 회복 |
| 스턴 | 몬스터를 5초간 멈춤. 3회 | 위기 탈출 |

사용 횟수는 층을 옮기거나 다시 참가해도 이어진다.

## 6. 파밍 아이템

층마다 방 곳곳에 놓여 있다. 한 방에 하나씩, 다음 층 도착 방·임무 장치·몬스터 시작 자리 근처는 비워 둔다.

| 아이템 | 효과 | 층마다 개수 (1·2·3·4인) |
| --- | --- | --- |
| 탄알집 | 예비 탄 보충 | 2 · 3 · 4 · 5 |
| 주사기 | 3초 사용, 체력 30 회복. 쓰는 동안 느려짐 | 2 · 3 · 3 · 4 |

- 이미 들렀던 층으로 다시 가면, 그때 남겨 둔 아이템만 남아 있다.
- 임무 물건(검역 카드, 관리자 카드, 전력 셀, 공구 등)도 같은 칸에 든다. 전력 셀은 무거워서 1개만 들 수 있고, 드는 동안 달리기·사격을 못 한다.

## 7. 몬스터

체력과 공격력은 3인 기준이다. 인원에 따라 체력이 바뀐다([11. 인원별 난이도](#11-인원별-난이도)).

| 몬스터 | 체력 | 공격 | 행동 |
| --- | --- | --- | --- |
| 쪼꼬미 (작은 몬스터) | 300 | 15 | 빠르게 순찰하며 대원을 찾음. 발견하면 **비명**을 질러 주변 몬스터를 부름 |
| 개구리형 | 450 | 20 (착지 40) | 벽·천장에 붙어 매복. 7m 안의 **서 있는** 대원을 보면 0.6초 경고 뒤 덮침. 앉은 대원은 못 봄 |
| 촉수형 | 900 | 25 | 눈이 없음. **소리**가 난 곳으로 찾아옴 |
| 눈 있는 대형 | 1200 | 40 | 시야로 대원을 찾아 쫓아옴 |
| 눈 없는 대형 | 1800 | 60 | 느리지만 강함. 소리 난 곳으로 가서 20초 동안 주변을 수색. 가까이 오면 내려치기 |

공통 규칙
- **맞으면 느려짐**: 맞을 때마다 잠깐 느려진다. 3초 안에 여러 발을 맞으면 움찔하며 멈춘다(그 뒤 3초는 다시 움찔하지 않음).
- **안 맞으면 회복**: 30초 동안 맞지 않으면 20초에 걸쳐 체력이 가득 찬다. 한 번에 몰아서 쏴야 한다.
- **쓰러지면 끝**: 쓰러진 몬스터는 다시 일어나지 않는다. 다만 층을 다시 오면 처음부터 다시 있다.
- **어둠 속 표시**: 몬스터 몸에만 닿는 옅은 빛과 발광 무늬로, 어두운 곳에서도 실루엣이 살짝 보인다.

## 8. 소리 규칙

몬스터 대부분이 소리에 반응하므로, 소리를 줄이는 것이 핵심 전략이다.

| 소리 | 들리는 거리 | 반응하는 몬스터 |
| --- | --- | --- |
| 걷기 발소리 | 4m | 쪼꼬미, 촉수형, 눈 없는 대형 |
| 달리기 발소리 | 9m | 위와 같음 |
| 앉아서 이동 | 없음 | - |
| 총소리 | 18m | 소리에 반응하는 몬스터 전부 |
| 쪼꼬미 비명 | 35m | 촉수형, 눈 없는 대형 |
| 버티기 임무 장치 (2~4층) | 30m, 35초마다 (끝나기 30초 전부터 10초마다) | 소리에 반응하는 몬스터 전부 |
| 1층 탈출선 점화 | 30초마다 | 소리에 반응하는 몬스터 전부 |

## 9. 층별 임무

층마다 임무를 끝내야 아래층 계단이 열린다. 위층으로 올라가는 것은 언제나 가능하다(5층 제외).

### 5층 · 승무원 구역 (시작 층)
- 게임 시작과 함께 경보와 함내 방송이 나온다. 목표와 기본 조작을 익히는 층.
- 임무 없이 바로 아래층으로 내려갈 수 있다.
- 몬스터: 쪼꼬미 1 (시작 방에서 먼 쪽 방들을 돌아다니며, 몬스터가 들어왔다는 것을 알려 줌)

### 4층 · 발전 구역
1. 전력 셀 3개를 보조 발전기에 끼우기 (무거운 물건, 한 명에 1개씩)
2. 냉각 밸브 2개 열기
3. 발전기 가동 → **90초 버티기**. 발전기실 안에 대원이 있어야 진행된다. 중간에 한 번 고장 → 공구로 수리
4. 배전실·전력 제어실 스위치 2개를 **동시에(10초 안에)** 올리기
5. A 계단 열림
- 몬스터: 촉수형 1, 쪼꼬미 1

### 3층 · 통제 구역
1. 서버 관리실 서버 3대 켜기 (켤 때 큰 소리)
2. 보안실 문이 열리고 감시 화면이 켜짐 → 감시 지도에서 몬스터·대원 위치 확인 가능
3. 책상 위 관리자 카드로 함교 문 2개 열기
4. 함교 상태 화면 확인
5. 데이터 보관실에서 **2분 내려받기**. 방 안에 대원이 있어야 진행된다
6. 격납고 관제실 콘솔에서 데이터 전송
7. B 계단 열림
- 몬스터: 눈 있는 대형 1, 쪼꼬미 1, 개구리형 2

### 2층 · 화물·검역 구역
1. 화물 분류실에서 검역 카드 찾기
2. 검역 관제실에서 봉쇄 해제 → 장비 작업실 문 열림
3. 절단기 챙기기 → 정비 보관실에서 전력 모듈 꺼내기
4. 중앙 화물창 화물 리프트로 전력 모듈 내려보내기
5. 연료 커플러 찾기 (후보 8곳 중 무작위)
6. **90초 충전 버티기** + 밸브 수리
7. A 계단 열림
- 선택 목표: 승무원 기록 찾기 → 배터리
- 몬스터: 5종 모두

### 1층 · 격납고 (마지막 층)
1. 준비 3가지 (순서 없음, 나눠서 가능)
   - 전력 모듈과 공구를 **한 대원이 함께 들고** 보조 우주선 방에 설치
   - 연료 라인 연결
   - 고정 장치 2개를 **10초 안에** 모두 풀기
2. 발사 관제실에서 격납고 문 열기 → 경보가 울리고, 문 뒤에 갇혀 있던 촉수형·눈 없는 대형이 풀려남
3. 탈출선 점화 → **3분 버티기**
4. 살아 있는 대원 모두가 탈출선 탑승 구역에 3초 머물면 **탈출 성공**

## 10. 협동 장치

| 장치 | 내용 |
| --- | --- |
| 근거리 음성 | 가까이 있는 대원끼리 목소리가 들림 |
| 무전 | 무전기를 가진 대원끼리 거리와 상관없이 대화(V 키를 누르는 동안). 무전 중 목소리는 주변 4m에도 들림 |
| 동시 작동 | 4층 스위치, 1층 고정 장치처럼 떨어진 장치 두 개를 제한 시간 안에 함께 작동. 혼자 플레이하면 시간 제한 없음 |
| 버티기 | 2·3·4층과 1층에서 장치가 도는 동안 방을 지켜야 함. 소리가 몬스터를 부름 |
| 구출 | 쓰러진 동료의 고치를 5발 쏴서 구출 |
| 함께 이동 | 층을 옮길 때 살아 있는 대원 모두가 계단에 모여 각자 준비해야 함 |

## 11. 인원별 난이도

게임을 시작할 때의 인원으로 정하고, 중간에 누가 나가도 바꾸지 않는다.

| 항목 | 1인 | 2인 | 3인 | 4인 |
| --- | --- | --- | --- | --- |
| 몬스터 체력 | 0.4배 | 0.7배 | 1배 | 1.3배 |
| 버티기 시간 | 0.7배 | 0.9배 | 1배 | 1배 |
| 동시 작동 제한 시간 | 제한 없음 | 10초 | 10초 | 8초 |
| 탄알집 (층마다) | 2 | 3 | 4 | 5 |
| 주사기 (층마다) | 2 | 3 | 3 | 4 |
| 추가 몬스터 | - | - | 일부 층에 쪼꼬미 | 일부 층에 쪼꼬미·촉수형 |

## 12. 멀티플레이

- **방**: 방장이 방을 만들고, 다른 대원은 방 코드나 방 목록으로 참가한다. 인터넷 너머의 친구와도 연결된다(Unity Relay).
- **다시 참가**: 게임 도중 나가거나 연결이 끊겨도, 3시간 안이면 같은 게임에 다시 들어갈 수 있다. 체력·탄약·아이템이 그대로 돌아온다.
- **낯선 사람 막기**: 게임이 시작된 방에는 처음 시작한 대원만 다시 들어올 수 있다.
- **방장이 나가면**: 게임이 끝나고 모두 로비로 돌아간다.
- **판 기록**: 층을 떠날 때와 게임이 끝날 때 걸린 시간·피해 등을 기록해, 밸런스 조정에 쓴다.

## 13. 화면과 설정

- **설정 창**
  - 소리: 전체·배경음·효과음·음성 채팅·마이크 크기
  - 키: 마우스 감도와 키 13개 바꾸기
  - 그래픽: 자동·낮음·높음, 화면 모드(전체 화면·창 모드), 화면 비율
- **그래픽 자동 선택**: 내장 그래픽이나 그래픽 메모리가 적은 PC는 처음 켤 때 '낮음'으로 시작한다.
- **게임 중 메뉴(Esc)**: 계속하기, 설정, 게임 나가기. 게임은 멈추지 않는다.
