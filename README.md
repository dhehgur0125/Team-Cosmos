# VOID LAST

**함께 살아남는 협동 호러 게임**

버려진 우주선 5층에서 시작해 층마다 임무를 해결하고, 1층 탈출선으로 탈출하는 1~4인 온라인 협동 SF 호러 게임입니다.
어둠 속에서 소리를 쫓는 몬스터를 피하며, 동료와 역할을 나눠야 살아남을 수 있습니다.

- 장르: 1인칭 협동 호러 · 생존
- 인원: 1~4인 (온라인)
- 플랫폼: PC (Windows)
- 엔진: Unity 6

## 주요 특징

- **층마다 다른 임무**: 카드 찾기, 서버 켜기, 데이터 내려받기, 발전기 지키기, 탈출선 점화 등 5개 층에 각각 다른 목표가 있습니다.
- **성격이 다른 몬스터 5종**: 소리를 쫓는 몬스터, 숨어 있다 덮치는 몬스터, 비명으로 동료를 부르는 몬스터 등 종마다 행동이 다릅니다.
- **역할을 나누는 고유 아이템**: 대원마다 아래 4가지 중 하나를 고릅니다. 같은 아이템은 한 명만 고를 수 있습니다.
- **음성 채팅**: 가까이 있는 대원끼리 들리는 근거리 대화와, 무전기를 가진 대원끼리 멀리서도 들리는 무전이 있습니다.
- **협동 장치**: 여럿이 동시에 눌러야 하는 스위치, 쓰러진 동료 구출, 함께 모여야 하는 층 이동이 있습니다.
- **온라인 플레이**: 방 코드로 참가할 수 있습니다. 연결이 끊겨도 같은 게임에 다시 참가할 수 있고, 인원수에 따라 난이도가 자동으로 맞춰집니다.

### 고유 아이템

| 아이템 | 효과 |
| --- | --- |
| 스캔 | 임무 물건·목표·쓰러진 동료 위치를 알려 줌 (대신 눈 없는 몬스터가 몰려옴) |
| 무전 | 무전기 2개로 시작, 하나는 동료에게 줄 수 있음 |
| 힐러 | 나와 동료의 체력 회복, 3회 |
| 스턴 | 몬스터를 5초간 멈춤, 3회 |

## 게임 흐름

`처음 화면` → `로비` (방 만들기·참가, 고유 아이템 고르기) → `5층` → `4층` → `3층` → `2층` → `1층` → 탈출

| 층 | 목표 |
| --- | --- |
| 5층 | 시작 층. 함내 방송과 함께 상황을 파악하고 아래층으로 내려감 |
| 4층 | 전력 셀 3개·냉각 밸브 2개 → 발전기 90초 지키기 → 스위치 2개 동시에 누르기 |
| 3층 | 서버 3대 켜기 → 관리자 카드 → 함교 문 열기 → 데이터 2분 내려받기 → 전송 |
| 2층 | 검역 카드 → 봉쇄 해제 → 전력 모듈 → 화물 리프트 → 연료 연결 → 90초 충전 버티기 |
| 1층 | 탈출선 준비 3가지 → 격납고 문 열기 → 점화 3분 버티기 → 생존자 모두 탑승해 탈출 |

층을 옮길 때는 살아 있는 대원 모두가 계단에 모여 각자 `F`를 눌러야 합니다.
모두 쓰러지면 게임 오버가 되고, 같은 방 대기실로 돌아갑니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| `Shift` | 달리기 (지구력 소모) |
| `Ctrl` | 앉기 (발소리 없음) |
| `Space` | 점프 |
| 왼쪽 클릭 / 오른쪽 클릭 | 사격 / 조준 |
| `F` | 상호작용 (줍기·장치·문·층 이동) |
| `Q` | 버리기 |
| `R` | 장전 |
| `E` | 손전등 (권총을 들고 있을 때) |
| `V` | 무전 (누르는 동안, 무전기가 있을 때) |
| `M` | 마이크 끄기·켜기 |
| `1` ~ `6` | 물건 칸 고르기 |
| `Esc` | 메뉴 (설정·게임 나가기) |

키는 설정 창의 Key 탭에서 바꿀 수 있습니다.

## 시작하기

1. 저장소를 받습니다.
   ```
   git clone https://github.com/dhehgur0125/Team-Cosmos.git
   ```
2. Unity Hub에서 **Unity 6000.4.9f1**로 프로젝트 폴더를 엽니다. 처음 열 때는 시간이 오래 걸릴 수 있습니다.
3. 바로 시험해 볼 때는 층 씬(예: `Assets/Map/Scenes/Floors/Stage2_Ship_2f.unity`)을 열고 Play를 누릅니다. 씬에 있는 대원으로 혼자 플레이할 수 있습니다.
4. 온라인으로 플레이할 때는 `Assets/Map/Scenes/Start.unity`에서 Play → 로비에서 방 만들기 → 게임 시작 순서로 진행합니다.

> [!NOTE]
> 방 만들기·참가와 음성 채팅은 Unity 클라우드 서비스(Multiplayer Services, Relay, Vivox)를 사용합니다.
> 에디터가 팀의 Unity 클라우드 프로젝트에 연결되어 있어야 하며, 연결되어 있지 않으면 혼자 플레이만 할 수 있습니다.

## 폴더 구조

```
Assets/
├─ Map/
│  ├─ Scenes/          시작·로비 씬, Floors/ 층별 게임 씬, Stage2_Ship.unity (맵 편집용 원본)
│  ├─ Script/          멀티플레이, 층 이동, 임무, 설정, 밸런스
│  └─ Editor/          씬 생성·설정 메뉴 (Tools/VOID LAST/...)
├─ Player/             대원 조작·체력·인벤토리·아이템
├─ Monster/            몬스터 AI·프리팹
├─ VoiceChat/          음성 채팅 (Vivox)
└─ Resources/          밸런스 수치(GameBalance), 아이템 프리팹
Docs/                  작업 인수인계 문서
Backups/               큰 변경 전 백업한 씬·스크립트
```

> 게임 씬은 `Stage2_Ship.unity` 원본을 층별로 나눠 만듭니다(메뉴 **Tools/VOID LAST/Multiplayer/9 Split Stage2 Into Floor Scenes**). 맵 수정은 원본에서 하고, 다시 나누면 층 씬을 직접 고친 내용은 덮어써집니다.
